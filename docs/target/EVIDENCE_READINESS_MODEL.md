# Evidence Readiness Model

> **Milestone 9**

| Status | Meaning |
|--------|---------|
| `declared` | Seeded requirements exist for the metric |
| `not_applicable` | No requirements seeded / not a reportable KPI |
| `incomplete_hint` | Reserved for future fulfillment tracking |
| `unknown` | Lookup unavailable |

Milestone 9 declares requirements; it does **not** verify that evidence artefacts were submitted.
