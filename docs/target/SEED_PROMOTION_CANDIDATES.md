# Seed Promotion Candidates

This path documents the **policy location** for human-readable seed promotion proposals.

Runtime artifacts are written by `AdminReviewService.promote_to_seed` to:

- `generated/seed_promotion/SEED_PROMOTION_CANDIDATES.md`
- `generated/seed_promotion/seed_promotion_report.json`
- `generated/seed_promotion/generated_seed_candidates.json`

See [SEED_PROMOTION_POLICY.md](SEED_PROMOTION_POLICY.md). Canonical `cloud_metrics/registry/seed/data.py` is never modified automatically.
